# Swetha S — Developer Portfolio

A creative, responsive, and interactive developer portfolio built with **React, Vite, and regular CSS**. Designed to showcase my work, technical skills, and experience as a Full Stack Developer and aspiring Software Development Engineer (SDE).

## ✨ Features

- Responsive design for desktop, tablet, and mobile.
- Clean, modern UI with a warm ivory, charcoal, sage green, and lilac colour palette.
- Interactive project cards with expandable details.
- Project category filtering.
- Light and dark theme toggle.
- Smooth animations and scroll-based reveal effects.
- Contact section with email-copy functionality.
- Dedicated sections for About, Projects, Experience, Skills, Achievements, and Contact.

## 💻 Run Locally

### Prerequisites

- Node.js (LTS version)
- npm
- Git (optional)

### Installation

1. Clone the repository or download the project.
2. Open the project folder in VS Code.
3. Open the terminal and install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build for Deployment

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

This portfolio can be deployed using **Vercel** or **Netlify** with the default Vite build configuration.

- Build command: `npm run build`
- Output directory: `dist`
