# Swetha S — Portfolio

A responsive, interactive personal portfolio built with React, Vite, and regular CSS.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
npm run preview
```

Deploy the project to Vercel or Netlify using the default Vite settings.

## Before publishing

- Confirm that the experience dates and project descriptions are still accurate.
- Add real project demo and GitHub links where available.
- Add screenshots or case studies for the projects.
- If you want a downloadable resume button, add your PDF to `public/` and link it from the hero.
- Review contact and social links.
